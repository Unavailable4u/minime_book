# Self-hosted fonts

Latin subset woff2 files copied unmodified from the npm packages below (pinned, version 5.3.0 each).
Licences (SIL Open Font License 1.1) are in `LICENSES/`.

| Family | Package | Files |
|---|---|---|
| Sora (UI) | `@fontsource/sora@5.3.0` | 400, 600, 700 |
| STIX Two Text (chapter prose) | `@fontsource/stix-two-text@5.3.0` | 400, 600, 700, 400 italic, 600 italic |
| JetBrains Mono (code) | `@fontsource/jetbrains-mono@5.3.0` | 400, 500, 700 |

To refresh: `npm i @fontsource/<name>@<version>` somewhere outside the repo and copy the `latin-<weight>-<style>.woff2` files.
