⚡ Book Synchronization Note: How this Initial Spec Connects to the Local-First Overrides (O1–O8)

This standalone HTML document is the initial product & design specification for M2C. When the engineering execution plan was locked, 8 architectural overrides (O1–O8) were established so M2C runs 100% local-first with near-zero server cost and shares a single account and credit pool with MiniMe Web:

  • O1 · Local-First Data Placement: Your device is the source of truth (local repo/files, local SQLite state, local shell/cron/channels/browser, local OS keychain/Argon2id vault). The MiniMe server stores only a content-free usage_ledger and an ephemeral Redis resume buffer (2 hours, max 500 events / 256 KB).
  • O2 · One Account, One Cap, One Shared Ledger (0012 / S01): M2C uses your existing MiniMe subscription (Free $0 / Basic $9 / Moderate $29 / Ultimate $79) and logs into the single shared usage_ledger with surface='m2c' — never a separate billing pool.
  • O3–O5 · Shared minicore/ Package & Routes: Shared loop/router primitives live in minicore/; server endpoints mount at /api/codeagent/*.
