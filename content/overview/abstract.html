MiniMe is a personal, workspace-centered AI operating environment in which a chat does not disappear when the answer ends: work is promoted into a durable workspace, organised into stages from research through planning, building, testing and growth, and kept available to later chats and tools. A request enters through a JWT-checked API, is tried first by a cheap relay of starter agents, and otherwise is classified, planned as a graph of roles and run by agent modules that call model providers with quota-aware fallback. Results are kept on a namespaced JSON bus and in Postgres, and pushed back to the browser over a realtime relay. Two device-side products extend the same server: M2C, a coding agent whose files stay on your machine under a local policy engine and sandbox, and Menux, an automation node that asks for approval before it acts. FBEBC is a separate research track, and the code in this repository covers MiniMe, the M2C client and its protocol, while Menux and FBEBC exist so far as documents.
