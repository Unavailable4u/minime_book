How this Atlas stays true

  • Numbers come from the code. Every count above is read from data/census.json (MiniMe's census script) or from the Graphify graph, and is shown with the commit and day it describes.
  • One command refreshes it. python scripts/update_all.py regenerates the census and graph data, rebuilds the search index, and runs every check before anything is published.
  • What cannot come from code says so. Tests, Finance, the Roadmap and the book keep their own “Built … from commit …” labels. If the chip at the top is amber, two of the sources disagree.
